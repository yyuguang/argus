# API设计规范

# 文档信息
- 文档名称：API规范
- 当前状态：生效中
- 最近更新阶段：初始化
- 最近更新原因：统一接口风格

---

## 1. 基础规范

- 遵循 RESTful
- URL 使用名词，不使用动词
- 版本统一：/api/v1/

---

## 2. URL设计

正确：
- GET /api/v1/orders/{id}
- POST /api/v1/orders

错误：
- /getOrder
- /createOrder

---

## 3. 请求规范

- 使用 DTO
- 禁止大量 @RequestParam
- 分页统一结构

---

## 4. 返回规范

统一返回结构：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

## 5. 状态码规范

- 200：成功
- 非200：业务错误

------

## 6. 错误处理

- 错误信息必须清晰
- 禁止返回“系统错误”

------

## 7. 幂等性

必须保证：

- 创建接口幂等
- 支持重试

------

## 8. 分页规范

统一字段：

- pageNo
- pageSize
- total

------

## 9. 安全规范

- 必须鉴权
- 禁止返回敏感信息

------

## 10. 日志与追踪

必须支持：

- traceId
- 请求日志

------

## 11. AI输出要求

生成接口时必须包含：

- URL
- 请求示例
- 响应示例
- 字段说明
- 错误场景
